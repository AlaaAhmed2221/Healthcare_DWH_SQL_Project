# Healthcare Data Warehouse and Analytics Project

Welcome to the **Healthcare Data Warehouse Project** repository! 🚀

---

## 🏗️ Data Architecture

The data architecture for this project follows the **Medallion Architecture**, consisting of **Bronze**, **Silver**, and **Gold** layers:

1. **Bronze Layer**: Stores raw healthcare data as-is from the source systems. Data is ingested from Excel/CSV files into the SQL Server database.

2. **Silver Layer**: This layer includes data cleansing, standardization, validation, and transformation processes to prepare the healthcare data for analysis.

3. **Gold Layer**: Houses business-ready healthcare data modeled into a **Star Schema** required for reporting and analytics.

---

## 📖 Project Overview

This project involves:

1. **Data Architecture**: Designing a modern Healthcare Data Warehouse using the **Medallion Architecture** with Bronze, Silver, and Gold layers.

2. **ETL Pipelines**: Extracting, transforming, and loading healthcare data from source files into the data warehouse.

3. **Data Modeling**: Developing fact and dimension tables optimized for analytical queries and healthcare reporting.

4. **Data Quality**: Cleaning and standardizing patient, doctor, appointment, treatment, and billing data to ensure accurate and reliable analysis.

5. **Analytics & Reporting**: Creating SQL-based reports and dashboards to provide actionable insights into healthcare operations and performance.
